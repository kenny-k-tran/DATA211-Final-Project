# DATA211-Final-Project
DATA 211 Final Project: Comparing Weekday and Weekend Screen Time

For my final project, I wanted to find out whether I spend more time on my phone during weekdays or weekends. I collected 21 consecutive days of screen-time data using my iPhone's Screen Time feature, from October 19 to November 8, 2026.

I recorded my daily screen time in minutes and separated the data into weekday and weekend groups. Using R, I created graphs and performed a two-sample t-test to compare my average screen time.
